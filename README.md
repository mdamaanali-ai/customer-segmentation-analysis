# customer-segmentation-analysis
Customer Segmentation Project using Python and scikit-learn to analyze customer behavior, purchase patterns, and demographics. The project uses clustering techniques to identify meaningful customer segments and provides visual insights into customer characteristics, helping businesses understand preferences and support targeted marketing strategies.
